# Сторонние компоненты

NEXUS использует программные компоненты сторонних разработчиков. Ниже перечислены
их лицензии и условия распространения. Все сведения проверены по официальным
репозиториям проектов.

---

## Сетевые ядра

### Xray-core

- **Правообладатель:** Project X (XTLS)
- **Лицензия:** Mozilla Public License 2.0 (MPL-2.0)
- **Исходный код:** https://github.com/XTLS/Xray-core
- **Как используется:** запускается отдельным процессом; исходный код не
  изменялся, компонент не встраивается в код NEXUS.

MPL-2.0 разрешает распространение исполняемого файла в составе продукта при
условии, что получатель проинформирован о доступности исходного кода. Ссылка
выше выполняет это требование.

### sing-box

- **Правообладатель:** nekohasekai (SagerNet)
- **Лицензия:** GNU General Public License 3.0 **с дополнительным условием**
- **Исходный код:** https://github.com/SagerNet/sing-box
- **Как используется:** загружается отдельно и запускается как самостоятельный
  процесс для протокола Hysteria2.

> Дополнительное условие автора: *«no derivative work may use the name or imply
> association with this application without prior consent»* — производные работы
> не вправе использовать название sing-box или подразумевать связь с проектом
> без предварительного согласия.

**Что это означает для NEXUS.** Компонент не входит в состав установщика: он
загружается с официального репозитория при первом использовании протокола
Hysteria2. Таким образом NEXUS не выступает распространителем GPL-программы, а
пользователь получает её напрямую от авторов. NEXUS запускает sing-box отдельным
процессом и не связывается с ним на уровне кода, поэтому условия GPL не
распространяются на исходный код NEXUS.

Название sing-box упоминается исключительно для указания происхождения
компонента и не используется в оформлении продукта.

## Что нужно сделать при изменении состава компонентов

1. Проверить лицензию нового компонента **в его репозитории**, а не по
   справочникам: у sing-box, например, GitHub показывает «Other», и реальное
   условие видно только в тексте файла.
2. Компоненты под GPL и подобными копилефт-лицензиями не включать в установщик —
   загружать с официального источника при первом использовании.
3. Добавить запись в этот файл и в раздел «О программе».
