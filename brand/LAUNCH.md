## Порядок публикации

Не вываливайте всё сразу — канал должен выглядеть живым, а не свалкой.

| Когда | Что | Зачем |
| --- | --- | --- |
| Сначала | Оформить канал, закрепить пост №1 | Человек, зашедший по ссылке, сразу понимает, куда попал |
| Через час | Пост №2 — релиз 1.2.7 | Первая новость, есть что скачать |
| Следующий день | Пост №3 — короткая инструкция | Канал не молчит после запуска |

## Пост №1 — закрепить

```
NEXUS — сетевые инструменты для Windows в одном окне

Что умеет:
— Обход блокировок сайтов
— Доступ к Telegram, когда он не работает
— VPN по вашей подписке: VLESS, VMess, Trojan, Shadowsocks, Hysteria2
— Режим «весь трафик через VPN» и «только выбранные программы»

Без настройки конфигов и командной строки. Ничего не отправляется наружу:
настройки и ключи хранятся только на вашем компьютере.

Windows 10 и 11, 64 бита. Запускать от имени администратора.

⬇️ Скачать
github.com/folyaken/NEXUS-releases/releases/latest

❓ Вопросы и проблемы — в комментарии к этому посту
```

**Прикрепите:** скриншот главного экрана программы.

## Пост №2 — релиз

Соберите командой `npm run post` — текст берётся из `CHANGELOG.md`.
Для 1.2.7 получится примерно так:

```
🚀 NEXUS 1.2.7

🛠 Исправлено
— Обновление больше не останавливается на кнопке «Готово»: программа ставится и запускается сама.
— Стрелка на кнопках «Сканировать» стала тоньше.

⚡️ Улучшено
— Окно обновления показывает проценты, размер файла и три понятных шага.

⬇️ Обновиться
В программе: «О программе» → «Проверить» → «Скачать» → «Перезапустить и установить».
Установщик целиком: github.com/folyaken/NEXUS-releases/releases/latest

#nexus #обновление
```

**Прикрепите:** скриншот окна обновления с полоской загрузки.

## Пост №3 — инструкция

```
VPN только для одной программы

Иногда VPN нужен не всему компьютеру, а одной игре или мессенджеру.
Остальное пусть идёт напрямую — так быстрее и не ломаются банки с госуслугами.

Как включить:
1. Откройте вкладку Jey2Ray
2. Настройки → Приложения
3. «Добавить приложение» → отметьте нужные из списка запущенных
4. Выберите «VPN только для выбранных приложений»

Готово. Остальной трафик идёт мимо VPN.

#инструкция
```

## Пост №4 — опрос

Текст: `Каким режимом пользуетесь чаще?`

Варианты:
- Обход блокировок (без VPN)
- VPN — весь трафик
- VPN — только выбранные программы
- Только доступ к Telegram

Опрос показывает, что развивать в первую очередь, и оживляет канал.

## Чего не делать в первый день

- **Не публиковать всё подряд.** Четыре поста за неделю лучше, чем десять за час.
- **Не звать людей, пока канал пустой.** Сначала закреплённый пост и релиз,
  потом ссылки где-либо ещё.
- **Не обещать того, чего нет.** Если функция в планах — так и писать.
- **Не покупать подписчиков.** Мёртвая аудитория обрушивает охваты: Telegram
  показывает посты тем, кто читает, а таких не будет.

## Про исходный код

Репозиторий с кодом закрывается перед запуском (см. `RELEASE-READINESS.md`).
Людям он не нужен: им нужен установщик и понятная страница со списком версий.

Если спросят, почему код закрыт — честный ответ: «Программа развивается, код
закрыт. Сборки собираются из проверенных открытых компонентов, их список есть
в THIRD-PARTY-NOTICES рядом с программой».
