## Что это

NEXUS открывает доступ к сайтам и сервисам, которые не работают из-за блокировок.
Всё управление — в одном окне, без правки конфигов и командной строки.

## Что умеет

| Возможность | Зачем |
| --- | --- |
| **Обход блокировок** | YouTube, Discord и другие сайты открываются без VPN |
| **Доступ к Telegram** | Работает, когда мессенджер заблокирован |
| **VPN по вашей подписке** | VLESS, VMess, Trojan, Shadowsocks, Hysteria2 |
| **Режим TUN** | Весь трафик компьютера идёт через VPN |
| **Только выбранные программы** | VPN включается для конкретных приложений, остальное — напрямую |
| **Раздача в домашнюю сеть** | Телевизор, консоль и телефон ходят через ваш компьютер |
| **Свой список сайтов** | Добавьте адрес — он начнёт открываться сразу |
| **Обновление одной кнопкой** | Новая версия ставится сама и запускает программу |
| **Запуск вместе с Windows** | Защита включается до того, как вы откроете браузер |
| **Русский и английский** | Интерфейс переведён целиком |

## Установка

1. Скачайте `NEXUS-Setup-x.x.x.exe` со [страницы релизов](https://github.com/folyaken/NEXUS-releases/releases/latest).
2. Запустите установщик и следуйте шагам.
3. Запускайте NEXUS **от имени администратора** — без этого не работают обход
   блокировок и режим TUN: им нужен доступ к сетевому драйверу.

**Требования:** Windows 10 или 11, 64 бита.

> **Windows покажет предупреждение SmartScreen.** Так бывает у всех программ без
> платного сертификата подписи. Нажмите «Подробнее» → «Выполнить в любом случае».

## Обновление

Программа проверяет новую версию сама. Когда она выйдет, рядом с пунктом
«О программе» появится зелёная метка.

**«О программе» → «Проверить» → «Скачать» → «Перезапустить и установить».**
Дальше NEXUS обновится и откроется сам — нажимать ничего не нужно.

## Частые вопросы

**Нужна ли подписка VPN?**
Для обхода блокировок и Telegram — нет, они работают сами по себе. Для VPN нужна
ваша подписка: вставьте ссылку провайдера, серверы появятся в списке.

**Куда уходят мои данные?**
Никуда. Настройки, профили и ключи хранятся только на вашем компьютере.
Программа не отправляет статистику и не требует регистрации.

**Не запускается режим TUN.**
Проверьте, что NEXUS запущен от имени администратора. Если не помогло —
пользуйтесь режимом PROXY и напишите в чат, разберёмся.

**Антивирус ругается на установщик.**
Обход блокировок использует сетевой драйвер — антивирусы относятся к такому
настороженно. Файлы собираются из открытых исходников официальных проектов.
