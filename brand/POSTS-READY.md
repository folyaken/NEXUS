## Пост №1 — закрепить (публиковать первым)

> К посту приложить **скриншот главного экрана** программы.
> После публикации: нажать на пост → «Закрепить».

```
NEXUS — сетевые инструменты для Windows в одном окне

Что умеет:
— Обход блокировок сайтов: YouTube, Discord и другие
— Доступ к Telegram, когда он не работает
— VPN по вашей подписке: VLESS, VMess, Trojan, Shadowsocks, Hysteria2
— Режим «весь трафик через VPN» и «только выбранные программы»
— Раздача на устройства домашней сети: ТВ, консоль, телефон
— Свой список сайтов для обхода
— Обновление одной кнопкой

Без настройки конфигов и командной строки. Ничего не отправляется наружу:
настройки и ключи хранятся только на вашем компьютере.

не работают обход блокировок и режим TUN.

При установке Windows покажет предупреждение SmartScreen: программа пока
без платного сертификата подписи. Нажмите «Подробнее» → «Выполнить в любом
случае».

⬇️ Скачать
github.com/folyaken/NEXUS-releases/releases/latest

```

## Пост №3 — инструкция (на следующий день)

> Приложить **скриншот Jey2Ray** со списком приложений.

```
VPN только для одной программы

Иногда VPN нужен не всему компьютеру, а одной игре или мессенджеру.
Остальное пусть идёт напрямую: так быстрее, и сайты банков с госуслугами
не начинают ругаться на «вход из другой страны».

Как включить:
1. Вкладка Jey2Ray
2. Настройки → Приложения
3. «Добавить приложение» → отметьте нужные из списка запущенных
4. Выберите режим «VPN только для выбранных приложений»

Готово. Через VPN пойдёт только то, что вы отметили.

Обратный вариант тоже есть: «Напрямую для выбранных приложений» — когда
VPN нужен всему, кроме пары программ.

#инструкция
```

## Пост №5 — про приватность (запасной, на конец недели)

Хорошо заходит: людей волнует, куда уходят их данные.

```
Куда NEXUS отправляет ваши данные

Никуда.

— Настройки, профили VPN и ключи подписок лежат только на вашем компьютере,
  в папке пользователя. В интернет они не уходят.
— Регистрация не нужна. Аккаунта нет вовсе.
— Статистика не собирается: ни какие сайты вы открываете, ни сколько времени
  работает программа.
— В сеть NEXUS ходит ровно за двумя вещами: проверить новую версию
  и обновить список серверов вашей подписки.

Идентификатор устройства (HWID) в разделе «О программе» считается локально
и нужен только тем VPN-панелям, которые сами его запрашивают.

#приватность
```

## Что подготовить до публикации

**Скриншоты — три штуки:**

| Для поста | Что снять |
| --- | --- |
| №1 | Главный экран «Обзор» целиком |
| №2 | Окно «О программе» с карточкой обновления |

Как снимать: тёмная тема, окно развёрнуто, вокруг ничего лишнего.
Клавиша `Alt + PrintScreen` снимает только активное окно.
