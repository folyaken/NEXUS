# NEXUS — видео-обзор

**Файл:** `nexus-overview.mp4`

**Параметры:** 1920×1080 (16:9) · 30 fps · 14,7 сек · H.264 + AAC · ~2,7 МБ

**Что в кадре:**

1. **Интро** — логотип и фирменный стиль NEXUS.
2. **Панель** — окно приложения: модули Jey2Ray VPN, Zapret, TG WS Proxy, DNS Guard,
   статистика и статусы.
3. **Jey2Ray VPN** — подключение в один клик, список серверов с задержкой,
   режимы Proxy/TUN, локальный SOCKS 127.0.0.1:10808.
4. **Аутро** — слоган и ссылка на репозиторий.

---

## Описание для публикации (YouTube / TikTok / VK и т.п.)

> **NEXUS — Network Control Plane**
>
> Единый центр управления сетью: VPN-клиент на Xray-core, модули Zapret и
> прокси для Telegram, журнал событий и автозапуск — всё в одном тёмном
> неоновом интерфейсе. Быстро, локально и под твоим контролем.
>
> Stack: Electron · React · TypeScript · Vite. Windows / Linux.

## Как пересобрать

```bash
node /home/user/vtools/render.js      # генерирует 4 кадра (frames/)
node /home/user/vtools/assemble.js    # собирает mp4 + накладывает озвучку
```

Озвучка генерируется отдельно (voice-00) и лежит в `vo.mp3` (темп 1.12× при монтаже).
