# NEXUS — видео-обзор

**Файл:** `nexus-overview.mp4`

**Параметры:** 1920×1080 (16:9) · 30 fps · ~16 сек · H.264 + AAC · ~0,7 МБ

## Что в кадре

Интерфейс воспроизведён по исходному коду приложения (`src/renderer/*.tsx`, `styles.css`)
с фирменными шрифтами NEXUS (Inter / Space Grotesk / JetBrains Mono), палитрой и разметкой.

1. **Интро** — логотип NEXUS.
2. **Панель** — живое окно: сайдбар, hero, статистика, карточки модулей (Обход DPI, TG WS Proxy, ExitLag SDK, DNS Guard) и панель SYSTEM PULSE.
   - курсор наводится на тумблер TG WS Proxy и «кликает» — тумблер переключается, статус меняется, счётчик «АКТИВНЫЕ» растёт.
3. **Jey2Ray** — список серверов с флагами и задержкой, кнопка питания.
   - курсор кликает по кнопке подключения — орбита загорается, «Выключено» сменяется на «Подключено · 47 мс», появляется таймер сессии и бейдж «ВКЛ».
4. **Аутро** — слоган и ссылка на репозиторий.

Анимации: имитация курсора с нажатиями, ripple-эффекты кликов, кинетический текст-накладки,
плавные переходы между экранами и русская озвучка.

## Описание для публикации (YouTube / TikTok / VK и т.п.)

> **NEXUS — Network Control Plane**
>
> Единый центр управления сетью: VPN-клиент на Xray-core, модули Zapret и
> прокси для Telegram, журнал событий и автозапуск — всё в одном тёмном
> неоновом интерфейсе. Быстро, локально и под твоим контролем.
>
> Stack: Electron · React · TypeScript · Vite. Windows / Linux.

## Как пересобрать

```bash
# 1) Шрифты из репозитория (woff2 -> ttf, веса 400-800)
python3 -m venv venv && ./venv/bin/pip install fonttools brotli
./venv/bin/python /home/user/vtools/convert_fonts.py

# 2) Сцены, спрайты курсора/тумблера, патчи состояний и подписи
node /home/user/vtools/render_scenes.js

# 3) Монтаж: курсор, клики, ripple, кинетический текст, озвучка
node /home/user/vtools/assemble2.js
```

Озвучка генерируется отдельно (voice-00) и хранится в `vo2.mp3`.
