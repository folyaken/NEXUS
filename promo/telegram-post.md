🖥 **NEXUS — Network Control Plane**

Единый центр управления сетью: VPN, обход блокировок и прокси для Telegram — всё в одном тёмном неоновом окне.

**Что внутри:**
• **Jey2Ray** — VPN-клиент на Xray-core (VLESS / VMess / Trojan / Shadowsocks), подключение в один клик
• **Обход DPI** (Zapret) — открывает YouTube, Discord и другие сайты без VPN
• **TG WS Proxy** — возвращает доступ к Telegram, когда он заблокирован
• Журнал событий, автозапуск, сворачивание в трей
• Раздача прокси в локальную сеть (Allow LAN)
• Всё работает локально — данные не отправляются в облако

**Стек:** Electron · React · TypeScript · Vite
**Платформы:** Windows · Linux
**Версия:** 1.1.9
