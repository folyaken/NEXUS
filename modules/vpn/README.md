# Jey2Ray (VPN Client)

- Бинарник Xray: `modules/bin/xray.exe` (скачивается с `XTLS/Xray-core`).
- Профили: `modules/configs/vpn/<id>.json`
- Рабочий конфиг: `modules/configs/vpn/generated_config.json`
- Лог: `modules/logs/vpn.log`

Управление только из вкладки **Jey2Ray**: вставка `vless://` / `vmess://` / `trojan://` / `ss://`.
