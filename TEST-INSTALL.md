# Как проверить установщик без второго компьютера

Проверка нужна, чтобы поймать то, что не видно при запуске из исходников: права
администратора, пути внутри установленной программы, работу ядер, вынесенных из
архива, и корректное удаление.

Варианты отсортированы от простого к сложному.

---

## Вариант 1. Песочница Windows — рекомендуется

Windows Sandbox встроена в Windows 11 Pro, Enterprise и Education. Это чистая
временная копия системы: после закрытия всё исчезает бесследно, основную систему
испортить невозможно.

### Включение (один раз)

1. Нажмите `Win + R`, введите `optionalfeatures`, Enter.
2. Отметьте **«Песочница Windows»** (Windows Sandbox).
3. Нажмите OK и перезагрузите компьютер.

Если пункта нет — у вас редакция Home, переходите к варианту 2.

Дополнительно в BIOS должна быть включена виртуализация. Проверить: диспетчер
задач → «Производительность» → «Процессор» → строка «Виртуализация».

### Проверка

1. Откройте «Песочница Windows» из меню «Пуск».
2. Скопируйте установщик из `release\` в окно песочницы обычным перетаскиванием.
3. Пройдите сценарий из раздела «Что именно проверять» ниже.
4. Закройте окно — все следы удалятся автоматически.

**Ограничение:** песочница не имеет доступа к сети от имени внешнего адреса, но
для проверки установки, запуска и удаления этого достаточно. Полноценно
проверить VPN-подключение в ней не получится.

---

## Вариант 2. Отдельная учётная запись Windows

Подходит для любой редакции, включая Home. Не даёт полной чистоты, но проверяет
главное: как приложение ведёт себя без ваших настроек в `%APPDATA%`.

1. «Параметры» → «Учётные записи» → «Другие пользователи» → «Добавить».
2. Создайте локальную учётную запись без прав администратора.
3. Войдите в неё и установите приложение.

Так проверяется первый запуск «с нуля» и запрос прав UAC у обычного
пользователя — самый частый сценарий у реальных людей.

---

## Вариант 3. Виртуальная машина

Самый полный вариант: работает сеть, значит можно проверить VPN и модули
целиком.

- **VirtualBox** — бесплатен, https://www.virtualbox.org
- Образ Windows 11 для разработчиков (готовая виртуальная машина, срок действия
  ограничен): https://developer.microsoft.com/windows/downloads/virtual-machines

Понадобится около 30 ГБ на диске и 4 ГБ оперативной памяти для машины.

---

## Минимальный вариант без всего этого

Если ни один способ не подходит, часть проверки можно выполнить на своей
системе. Это менее надёжно, но лучше, чем ничего.

Перед установкой временно переименуйте папку с данными — так приложение
запустится «как впервые»:

```powershell
Rename-Item "$env:APPDATA\nexus-network-tools" "nexus-network-tools.backup"
```

После проверки верните обратно:

```powershell
Remove-Item "$env:APPDATA\nexus-network-tools" -Recurse -Force
Rename-Item "$env:APPDATA\nexus-network-tools.backup" "nexus-network-tools"
```

Так не проверяется поведение на системе без установленных зависимостей, но
первый запуск, права и удаление посмотреть можно.

---

## Что именно проверять

| Шаг | Ожидаемый результат |
| --- | --- |
| Установка | Windows запрашивает права администратора, показывается текст лицензии |
| Ярлыки | Созданы на рабочем столе и в меню «Пуск» |
| Первый запуск | Окно открывается, в консоли нет ошибок кеша Chromium |
| «О программе» | Версия 1.1.1, раздел «Лицензии» заполнен |
| Обновление | Кнопка «Проверить» → «Канал обновлений не настроен в этой сборке» |
| Обход DPI | Модуль запускается без сообщения о нехватке прав |
| Jey2Ray | VPN подключается — так проверяются ядра, вынесенные из архива |
| Настройки | Свои сайты и параметры сохраняются после перезапуска |
| Удаление | Задаётся вопрос об удалении настроек |
| **После удаления** | **Интернет работает** |

### Самое важное — последняя строка

Подключите VPN и, **не отключая его**, удалите программу. После удаления
проверьте, открываются ли сайты.

NEXUS на время работы прописывает себя в системные настройки прокси Windows.
Если удаление не вернёт их в исходное состояние, система продолжит отправлять
трафик на локальный порт, которого больше нет, и интернет пропадёт полностью.
Это исправлено в патче 38, но проверить нужно на реальной установке.

### Если интернет всё-таки пропал

Восстановить вручную:

```powershell
Set-ItemProperty -Path "HKCU:\Software\Microsoft\Windows\CurrentVersion\Internet Settings" -Name ProxyEnable -Value 0
```

Либо: «Параметры» → «Сеть и Интернет» → «Прокси» → выключить «Использовать
прокси-сервер».
