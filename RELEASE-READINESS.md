Проверочный список перед первым постом в канал. Разделён на две части:
что уже сделано в коде и что нужно сделать вам руками на GitHub.

## Часть 1. Что закрыто в коде

### Ничего постороннего не уезжает пользователю

| Что проверено | Состояние |
| --- | --- |
| Упоминания среды разработки в файлах проекта | нет ни одного |
| То же внутри `package.json` (он попадает в `.exe`) | нет |
| Идентификатор приложения | `com.folyaken.nexus` |
| Исходники, тесты и документы в сборке | не попадают |
| Карты кода (`.map`), восстанавливающие исходник | не создаются |
| Комментарии «почему так сделано» в собранном коде | вырезаются |

Комментарии в проекте объясняют, какие были проблемы и как их обошли. Внутри
установленной программы это подсказка, где у неё слабые места, поэтому при
сборке они удаляются. В исходниках остаются.

### Программу трудно расковырять

| Защита | Как работает |
| --- | --- |
| Инструменты разработчика | выключены в установленной версии |
| Меню Electron | удалено — вместе с ним горячие клавиши F12 и Ctrl+Shift+I |
| Перехват клавиш | F12, Ctrl+Shift+I/J/C не доходят до страницы |
| Переход на чужой адрес | запрещён, окно грузит только свои файлы |
| Всплывающие окна | не открываются |
| Изоляция контекста | включена, Node в интерфейсе недоступен |
| Целостность `asar` | контрольные суммы считаются при сборке |

**Про целостность.** electron-builder записывает контрольные суммы архива с
кодом в манифест программы. Если подменить файл внутри установленного NEXUS,
Windows откажется его запускать. Это не защита от разбора — от неё в настольных
программах защиты не существует вовсе, — но подменить код у пользователя и
выдать это за оригинал не получится.

**Честно о границах.** Любое настольное приложение можно распаковать: `asar` —
это контейнер, а не шифр. Мы убрали то, что упрощает задачу (карты кода,
комментарии, инструменты разработчика) и закрыли подмену. Полностью скрыть
код от того, кто целенаправленно этим займётся, нельзя ни в Electron, ни где
бы то ни было ещё.

Всё перечисленное закреплено проверками в `tests/release-hardening.test.cjs` —
если что-то из этого случайно отключат, тесты упадут.

## Часть 2. Что сделать вам на GitHub

Мне доступ к настройкам репозиториев закрыт, эти шаги только вручную.

### Шаг 1. Витрина для людей

Открыть https://github.com/folyaken/NEXUS-releases/blob/main/README.md →
карандаш → заменить содержимое на текст из `brand/PUBLIC-README.md` → Commit.

Это единственная страница, которую увидят пользователи: что за программа,
что умеет, как поставить, частые вопросы.

### Шаг 2. Описание репозитория релизов

`NEXUS-releases` → шестерёнка справа от About → описание:

```
NEXUS — сетевые инструменты для Windows: обход блокировок, Telegram и VPN
```

### Шаг 3. Закрыть исходный код

**Только когда закончим работу над патчами** — пока репозиторий публичный,
работают ссылки на архивы патчей.

`NEXUS` → Settings → Danger Zone → Change repository visibility → **Private**.

После этого рабочие ветки станут не видны никому, кроме вас. Отдельно удалять
их не нужно.

> Релизы при этом никуда не денутся: они лежат в `NEXUS-releases`, и он
> остаётся открытым. Автообновление продолжит работать.

### Шаг 4. Проверить установщик на чистой машине

Перед тем как звать людей:

- [ ] Установщик запускается, показывает заставку с логотипом
- [ ] Программа стартует, обход блокировок работает
- [ ] VPN подключается, режим TUN работает
- [ ] Обновление находит новую версию и ставит её само
- [ ] После установки обновления программа открывается сама

## Часть 3. Известные ограничения

О них лучше знать заранее, чем услышать от пользователей.

**Windows покажет предупреждение SmartScreen.** Установщик не подписан
сертификатом — он стоит 300–400 $ в год. Люди нажимают «Подробнее» →
«Выполнить в любом случае». Об этом стоит написать прямо в закреплённом посте,
чтобы предупреждение не выглядело подозрительно.

**Антивирусы могут ругаться.** Обход блокировок работает через сетевой драйвер,
и антивирусы относятся к такому настороженно. Если начнутся жалобы — сборку
можно отправить в Microsoft на проверку через их форму для разработчиков.

**Программа требует прав администратора.** Без них не работают обход блокировок
и режим TUN. Это не прихоть: им нужен доступ к сетевому драйверу.
